WiFi

This page keeps the two Wi-Fi radios in separate roles so field work cannot accidentally remove the management connection.

Management · wlan0

Use this session for the Pi’s normal network connection. It starts with FFLF-ZONE, but you can enter another SSID to save it as a management network. Saved management profiles reconnect automatically; the PiKit hotspot is the fallback when none is available.

Use Saved management profiles to switch to a previously saved wlan0 profile. Use Nearby management networks to select a detected network; enter its password on the connection form if it is protected.

Field · wlan1

Use this session only for equipment, boat, or industrial networks. Connections made here are saved on wlan1 but do not reconnect automatically after a reboot.

Choose a detected network from Nearby field networks, or enter its SSID manually. Select Disconnect field radio when finished.

Monitor mode

Enable monitor mode takes wlan1 out of NetworkManager so it can listen for authorized wireless analysis. It cannot scan or join Wi-Fi while in monitor mode. Select Return to managed mode before connecting or scanning again.

Network lists

Each nearby-networks list shows about five networks at a time. Scroll inside the list to see additional scan results. Scan results are refreshed when the WiFi tab is loaded.

Only use monitor mode and access industrial/boat networks when you are authorized. The console is protected with HTTP Basic authentication.
